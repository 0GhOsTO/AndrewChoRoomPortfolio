About Me

I'm Andrew Cho, a Computer Science student at Boston University. I've been drawn to programming since I first saw how elegantly a language can be described through formal logic. Understanding the mathematical precision behind language design is what convinced me that building software is as much a craft as it is engineering — and I've been committed to mastering both ever since.

What I'm Working On

My current focus is on machine learning and full-stack development. I've been building a strong foundation in ML — from expectation-maximization to singular value decomposition — and applying that knowledge to real-world problems. At the same time, I'm deepening my software engineering skills by shipping production-quality applications from end to end.

Beyond Code

I play guitar and draw in my free time. Playing in a band taught me that great work comes from listening — syncing with other musicians requires the same attentiveness that makes a strong engineering team. Drawing gave me an appreciation for multiple perspectives: the same subject looks different to every artist, just like the same problem has many valid solutions in code. Both hobbies reinforced something I carry into every project — the best outcomes come from collaboration.

Code, art, or music — I'm driven by the challenge of solving problems and creating things that resonate with people.
